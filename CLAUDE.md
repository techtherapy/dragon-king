# Dragon King Sutra — working notes

## The site is trilingual. No change ships in one language only.

English lives at the root, Spanish under `es/`, French under `fr/`. **Every
change to page content must be made in all three.** Adding an English section
and leaving the Spanish and French behind is not a smaller change — it is a
broken one, and the build will refuse it.

Before finishing any change to page content, run:

```bash
python3 scripts/check_translation_parity.py
```

It fails the build (and `scripts/build_site.sh` runs it first) if the versions
drift in structure, in text, or in the generators' string tables. After
legitimately editing all three languages, re-record the text baseline with
`python3 scripts/check_translation_parity.py --record` and commit
`translations/parity.json`.

Where to make the edit depends on who produces the page — generated pages are
edited once in their generator, hand-authored pages three times. Full
methodology, recipes and the per-language glossaries:
**[docs/TRANSLATION.md](docs/TRANSLATION.md)**.

## Never edit generated files by hand

| File | Generated by |
|---|---|
| `read.html`, `es/read.html`, `fr/read.html` | `scripts/build_reader.py` |
| `treasure-vase-yoga.html`, `es/…`, `fr/…` | `scripts/build_practice.py` |
| `assets/dragon-hero.svg`, `waves.svg`, `sky-stars.svg`, `clouds-*.svg`, `vase-vision.svg`, `footer-crest.svg` | `scripts/generate_dragon.py` |
| `assets/mudra.svg` | `scripts/trace_mudra.py` (traces the owner's reference) |
| `assets/dharmaraksa.svg` | `scripts/trace_dharmaraksa.py` |
| `assets/vase-preparation.svg`, `casting-the-vase.svg`, `deco-*.svg` | `scripts/generate_practice_art.py` |
| `assets/og-image.jpg`, `og-image-es.jpg`, `og-image-fr.jpg` | `scripts/generate_og_images.py` |
| `assets/wenkai-reader.*.woff2` + `scripts/wenkai-subset.json` | `scripts/build_font_subset.py` |
| the Chinese font link in every page's `<head>` | `scripts/subset_font_links.py` |
| the SEO block in every page, `sitemap.xml`, `robots.txt` | `scripts/add_seo.py` |

Edits to those files are destroyed on the next run. Change the generator.

The sutra transcripts in `extra-content/` are primary sources and stay as
recorded — corrections go in the normalisers in `build_practice.py`'s
`paragraphs()`, so the record stays intact and the fix survives rebuilds.

## Build and deploy

```bash
bash scripts/build_site.sh      # parity check, SEO, assemble dist/
npx wrangler deploy             # Cloudflare Workers
```

`dist/` is the only thing published; the build fails if `scripts/`,
`translations/`, `extra-content/`, `docs/` or the source sutra HTML ever
land in it.

The build also refuses to publish if the reader has gained a Chinese character
the self-hosted subset font does not carry. Rebuild it — occasionally, only
when new Chinese text is added — with:

```bash
python3 scripts/build_font_subset.py
```

It needs no global installs: fonttools and the 15 MB source font live in
`~/.cache/dragon-king-fonts/`, and only the ~400 KB subset enters the repo.

Cloudflare's git-triggered builds have been unreliable — deploys in this
repo go out with `npx wrangler deploy` after pushing. Expect the edge to
serve a stale copy for a few seconds afterwards; re-check before concluding
a deploy failed.

## House style

- Mid-sentence: *dharma*, *buddhahood*, *buddhanature*, *buddhadharma* —
  lowercase. Names keep their capitals (Dharma Protectors, Buddha Dharma
  as a title).
- *Grandmaster*, one word. *Sakyamuni*, *Surangama* — no "h".
- Design language 紺紙金泥: gold line-art on deep indigo. New artwork is
  generated or traced into SVG, never a raster.
- No CSS `filter` on the line-art at phone widths — it rasterises the SVG at
  CSS resolution and softens it. Scope filters to `min-width: 981px`.
- The guru mantra is transliterated for each language's phonetics:
  *Om Guru Lian Sheng Siddhi Hum* (en), *Om Guru Lian Sheng Sidi Jom* (es),
  *Om Gourou Lian Sheng Siddhi Houm* (fr). Same for the Dragon King mantra —
  see the glossary tables in docs/TRANSLATION.md.
