# Dragon King Sutra — working notes

## The site is bilingual. No change ships in one language only.

English lives at the root, Spanish under `es/`. Before finishing any change
to page content, run:

```bash
python3 scripts/check_es_parity.py
```

It fails the build (and `scripts/build_site.sh` runs it first) if the two
versions drift in structure, in text, or in the generators' string tables.
After legitimately editing both languages, re-record the text baseline with
`python3 scripts/check_es_parity.py --record` and commit `translations/parity.json`.

Full methodology, recipes and translation conventions: **[docs/TRANSLATION.md](docs/TRANSLATION.md)**.

## Never edit generated files by hand

| File | Generated by |
|---|---|
| `read.html`, `es/read.html` | `scripts/build_reader.py` |
| `treasure-vase-yoga.html`, `es/treasure-vase-yoga.html` | `scripts/build_practice.py` |
| `assets/dragon-hero.svg`, `waves.svg`, `sky-stars.svg`, `clouds-*.svg`, `vase-vision.svg`, `footer-crest.svg` | `scripts/generate_dragon.py` |
| `assets/mudra.svg` | `scripts/trace_mudra.py` (traces the owner's reference) |
| `assets/dharmaraksa.svg` | `scripts/trace_dharmaraksa.py` |
| `assets/vase-preparation.svg`, `casting-the-vase.svg`, `deco-*.svg` | `scripts/generate_practice_art.py` |
| the SEO block in every page, `sitemap.xml`, `robots.txt` | `scripts/add_seo.py` |

Edits to those files are destroyed on the next run. Change the generator.

The sutra transcripts in `extra-content/` are primary sources and stay as
recorded — corrections go in the normalisers in `build_practice.py`'s
`paragraphs()`, so the record stays intact and the fix survives rebuilds.

## Build and deploy

```bash
bash scripts/build_site.sh      # parity check, SEO, assemble dist/
npx wrangler deploy             # Cloudflare Workers
```

`dist/` is the only thing published; the build fails if `scripts/`,
`translations/`, `extra-content/`, `docs/` or the source sutra HTML ever
land in it.

Cloudflare's git-triggered builds have been unreliable — deploys in this
repo go out with `npx wrangler deploy` after pushing. Expect the edge to
serve a stale copy for a few seconds afterwards; re-check before concluding
a deploy failed.

## House style

- Mid-sentence: *dharma*, *buddhahood*, *buddhanature*, *buddhadharma* —
  lowercase. Names keep their capitals (Dharma Protectors, Buddha Dharma
  as a title).
- *Grandmaster*, one word. *Sakyamuni*, *Surangama* — no "h".
- Design language 紺紙金泥: gold line-art on deep indigo. New artwork is
  generated or traced into SVG, never a raster.
- No CSS `filter` on the line-art at phone widths — it rasterises the SVG at
  CSS resolution and softens it. Scope filters to `min-width: 981px`.
